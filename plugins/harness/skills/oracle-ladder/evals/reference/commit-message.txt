fix[skills][specification]: require every spec to record its rejected alternatives

[PROBLEM]
A specification names the option it chose and stays silent about the options
it refused. A reader meets the winner alone, so the rejected options come back
as proposals the next time anyone reads the spec.

[ROOT-CAUSE]
The skill asked for a decision, not for the decision's frontier. Nothing in the
text made the losing options part of the artifact, so writers dropped them as
scaffolding once the choice was made.

[CHANGE]
The skill now requires each spec to list the alternatives it rejected and the
reason each lost. Recording the reason rather than the bare list is what stops
re-litigation: a name alone invites the reader to re-derive why it lost.

principal and is not yet written down as a rubric.
